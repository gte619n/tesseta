# Offline write contract classification. Each line: CATEGORY|METHOD path.
# Enforced by WriteContractTest — every live mutating endpoint must appear here
# and none may be NEEDS_FIX. Rationale per category: docs/reference/write-contract.md.
#
# KEY_GUARDED        create routed through SyncWriteContext.idempotentCreate (Idempotency-Key)
# DETERMINISTIC_ID   create/upsert whose doc id is client-supplied or deterministic
# SET_SEMANTICS      PUT/PATCH (or a set-toggle POST) that replays to the same state
# IDEMPOTENT_DELETE  DELETE — re-deleting converges
# NON_PERSISTING_POST POST that persists no durable user doc (search/lookup/stream/preview/auth/toggle)
# EXEMPT             non-idempotent but accepted (admin catalog/config, AI-cost, webhooks with own dedup)
#
# NOTE: the /v1 platform + /oauth endpoints are behind app.platform.enabled
# (off in the test profile) and are pinned separately by V1OpenApiSnapshotTest.
